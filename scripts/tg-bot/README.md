# Телеграм-бот ГДЗ НЭЛ

Бот канала [@gdz_nel](https://t.me/gdz_nel): по команде присылает случайную
задачу из приложения и может постить задачи в сам канал.

## Что умеет

| команда | что делает |
| --- | --- |
| `/start` | приветствие и кнопка на сайт |
| `/help` | список команд |
| `/task` | случайная задача с условием, ответом и ссылкой на решение |
| `/subject math` | случайная задача по предмету |
| `/post` | отправляет случайную задачу в канал (запускает админ) |

А ещё:

* `python bot.py --once` — один пост в канал и выход (удобно для cron);
* `python bot.py --daily-post` — сам постит задачу раз в сутки.

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather), забери токен.
2. Добавь бота **администратором** канала `@gdz_nel` (право «Публикация
   сообщений») — без этого `/post` не сможет писать в канал.
3. В корне репозитория есть `.env` (в `.gitignore`). Если его нет — скопируй
   `scripts/tg-bot/.env.example` в `.env` и заполни:

   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   TELEGRAM_CHANNEL_ID=@gdz_nel
   ```

   Токен нигде не хардкодится — только через переменные окружения.

## Запуск

```bash
cd scripts/tg-bot
pip install -r requirements.txt
python bot.py
```

Проверка токена без запуска:

```bash
python bot.py --once   # один пост в канал; если бот не админ — покажет ошибку
```

## Docker

```bash
docker build -t gdz-nel-bot scripts/tg-bot
docker run --rm --env-file .env \
  -e GDZ_DATA_DIR=/app/data \
  -v "$PWD/app/data:/app/data:ro" \
  gdz-nel-bot
```

## Где данные

Задачи читаются из `app/data/<subject>/<book>.json` (эта же папка, что у
сайта) и `app/data/catalog.json` — чтобы собирать ссылку вида
`…/app/#/6/math/vilenkin-6-1/1.10`. Переопределяется переменной
`GDZ_DATA_DIR`.

## Ограничения

* Это справочный сервис: условия — по учебникам, ответы даются для
  самопроверки, не как готовое домашнее задание «под копирку».
* Публикация в канал возможна только если бот — админ канала.
