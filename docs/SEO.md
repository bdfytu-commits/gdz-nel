Правила: title до 60 символов, description 120–160 символов, без «лучший» и
обещаний «списать». Везде бренд «ГДЗ НЭЛ» и конкретика: класс, предмет,
автор, тип решения.

- **Title:** ГДЗ НЭЛ — готовые домашние задания 1–11 класс

## Что уже сделано в коде

- 50 статических страниц в `seo/<slug>/index.html`: условие, решение, ответ,
  хлебные крошки, canonical, Open Graph, JSON-LD и ссылка на задание в
  приложении.
- ЧПУ: `/seo/vilenkin-6-1-1-1/`; картинки в `/seo/og/<slug>.png`.
- Все страницы добавлены в `sitemap.xml` блоком `seo-pages`.
- Индекс разборов: `/seo/`.

## Приоритет запросов

1. «автор + класс + номер» — длинный хвост, низкая конкуренция.
2. «автор + класс» — книги и разделы.
3. «гдз по предмету + класс» — только после накопления ссылок на страницы
   разборов; отдельные лендинги не плодить.
4. Новые страницы добавлять по 5–10 в неделю, чтобы не выглядеть дорвей-сетью.
