# Прогресс

Обновляется после каждой задачи. Сделано / в работе / ждёт.

## Сделано

- MVP (прошлая сессия): структура, лендинг, /app с хэш-роутингом, 8 тестовых JSON, проверка headless chromium.
- Задача 0: SPEC.md, RULES.md, TASKS.md, PROGRESS.md на диске.
- Задача 1: лендинг переработан — hero с точками и градиентом, карточки предметов (иконка, счётчики из stats.json, градиентная обводка, 3D-tilt 600px/4deg), «Как это работает» (3 шага), футер со ссылками. Проверено скриншотами.
- Задача 2: /app переработан — sticky-шапка с тенью, поиск в шапке (фильтр номеров на сетке, глобальный поиск по тексту), обложки учебников, сетка ≥56px с группами разделов и sticky-заголовками, экран задания (условие на #F5F5F5, решение по шагам, ответ в бирюзовой рамке, поделиться/скопировать/ошибка/избранное, prev/next), экраны избранного и недавних, тосты. e2e-тест из 23 проверок — всё зелёное.
- Задача 3: 31 SVG-иконка в /assets/img/icons/ (предметы и UI), подключаются через CSS-маску → цвет currentColor.
- Инфраструктура: scripts/write_stats.py (stats.json со счётчиками по предметам и учебникам), favicon.ico, apple-touch-icon, иконки PWA 192/512/maskable.

## В работе

## Известные ограничения

- нет JDK/Android SDK и sudo — APK (задача 7) будет заглушкой со скриптом и инструкцией.
- локальный предпросмотр: `uv run python -m http.server 8000` из корня, без него fetch не работает (file:// запрещён).
