# ТЗ: ГДЗ НЭЛ

Полное техническое задание. Источник — промт заказчика от 16.10.2026 (сохранён дословно по смыслу, структура цикла работ).

## Что делаем

Сайт с готовыми домашними заданиями (ГДЗ) для 6 класса МАОУ НЭЛ (Новосибирский экономический лицей):
статический сайт + приложение (/app) + лендинг для установки + PWA + APK через Bubblewrap.

## Ключевое условие: чистая статика

- HTML + CSS + vanilla JS. Никаких бэкендов, БД, фреймворков, сборщиков.
- Данные в JSON-файлах, читаются через fetch.
- Хостинг — GitHub Pages или Cloudflare Pages (бесплатно).
- APK — обёртка сайта через PWA + Bubblewrap.
- Запрещено: Flask, Django, Node.js, React, Vue, Svelte, Tailwind, Bootstrap, SASS, Webpack, Vite.

## Окружение пользователя

- ОС: Linux (Arch-based, Garuda Linux). Shell: FISH (bash-синтаксис не работает).
- Python через uv. sudo нет, системные пакеты не ставить.
- Редактор: micro или nano.

## Градиенты, 3D, анимации

- hero: linear-gradient(135deg, #1AA3A3 0%, #0070C0 100%); свечение radial-gradient(circle, rgba(26,163,163,0.15), transparent)
- кнопки на hover: переход к градиенту; карточки: лёгкий градиент #FFFFFF → #F5F5F5
- 3D только на карточках и интерактивных элементах: perspective(800px) rotateX(2deg) rotateY(-2deg), тень
- нажатие кнопок: scale(0.98) + «продавливание» тенью; номера заданий на hover: подъём 2-3px
- transition 150–250ms cubic-bezier(0.4, 0, 0.2, 1); появление карточек — fade-in + slide-up 20px через IntersectionObserver (один раз)
- переходы экранов /app: fade-out 200ms → fade-in 200ms; скелетоны с pulse 1.5s infinite
- всего 4–5 типов анимаций, не на каждом элементе

## JSON для заданий

```json
{
  "subject": "math",
  "textbook": "vilenkin-6-1",
  "author": "Виленкин Н.Я., Жохов В.И., Чесноков А.С.",
  "year": "2023–2026",
  "part": 1,
  "source": "parsed|ai-generated|manual",
  "sourceUrl": "https://...",
  "parsedAt": "2026-10-16T12:00:00Z",
  "tasks": [
    { "number": "1.1", "section": "§1. Вычисления и построения", "condition": "...", "solution": "...", "answer": "..." }
  ]
}
```

Про `number`: это строка. Новые учебники нумеруют задания с точкой («1.1», «4.13»),
а у учебников, где источник не даёт номеров упражнений (английский, биология, история,
обществознание), номер = «страница.порядковый_номер» («5.2»). Поиск, сетка и хэш-роутинг
работают со строковыми номерами; отсутствующие номера между соседними задачами
раздела рисуются серыми зачёркнутыми.

## Функционал /app

1. Шапка: логотип, название, поиск, переключатель темы.
2. Выбор предмета — карточки с 3D-эффектом.
3. Выбор учебника и части.
4. Сетка номеров (активные — градиент на hover, отсутствующие — серые зачёркнутые, группировка по разделам, sticky-заголовки).
5. Задание: условие, решение пошагово, ответ в бирюзовой рамке, назад/вперёд, крошки, поделиться, сообщить об ошибке.
6. Поиск по номеру и по тексту условия, подсветка, debounce 200ms.
7. Без перезагрузки, fetch. 8. Хэш-роутинг #/math/vilenkin-6-1/123.

## Функционал лендинга

Hero с градиентом/свечением/логотипом/двумя кнопками; секция «Что внутри» с 3D-tilt карточками и счётчиками; «Как это работает» — 3 шага; скриншоты — phone-frame с реальными скринами /app; футер #3C3C3C со ссылками.
