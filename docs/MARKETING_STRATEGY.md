# Стратегия легального маркетинга на месяц

## Позиционирование

ГДЗ НЭЛ — не «списать любой ценой», а быстро найти условие, разбор и ответ
для самопроверки. Это важно для школ, родителей и админов сообществ: мы не
обещаем контрольные без подготовки и не продаём готовые ответы в личку.

Короткая формула: «Нашёл номер — сверил шаги — понял, где ошибся».

Целевые аудитории:

1. Школьники 5–11 классов, которые ищут конкретный номер.
2. Родители, которые проверяют домашку и хотят видеть решение.
3. Учителя и репетиторы, которым нужен быстрый список задач для печати.
4. Локальные сообщества Новосибирска и НЭЛ.

## Что уже есть

- 310 тысяч заданий, 577 учебников, 1–11 классы.
- Поиск по номеру и тексту, избранное, недавние задания.
- Фото-режим, голосовой ввод, офлайн-учебники, общий PDF.
- Профиль с XP, серией дней и реферальной ссылкой.
- 70 SEO-страниц под длинные запросы и sitemap.
- Telegram-канал @gdz_nel, бот-администратор проверен.
- VK-группа: нужен токен и id своей группы для автопостинга.

## Правила, без которых не начинаем

- Никаких массовых личек, парсинга участников и добавления в чаты без
  приглашения.
- Никаких ботов, накрутки реакций и фейковых аккаунтов.
- В чужие сообщества — только после согласования с админом и по его правилам.
- В комментариях сначала полезный ответ, ссылка только если её просят или
  она уместна. Раскрываем, что мы автор проекта.
- Не публикуем персональные данные школьников. Для конкурсов — только
  добровольные заявки и без домашних адресов.
- Реклама у блогеров и в пабликах маркируется, если этого требует закон и
  площадка.

## Неделя 1. База и свои площадки

Задачи:

1. Проверить, что на проде открываются 70 SEO-страниц, sitemap и key-файл
   IndexNow.
2. Отправить sitemap в IndexNow, проверить индекс в Яндекс.Вебмастере и
   Google Search Console.
3. Заполнить шапку Telegram-канала: что это, для кого, ссылка на приложение,
   правила комментариев.
4. Оформить VK-сообщество: обложка, описание, ссылка, закреплённый пост
   с честным позиционированием.
5. Собрать 50–100 открытых сообществ через `scripts/find_groups.py` (нужен
   VK_ACCESS_TOKEN). Не писать им в первый день.
6. Выпустить 3 поста: знакомство, поиск по номеру, фото-режим.

Метрики недели: 70 страниц в sitemap, 3 поста, 10 переходов по UTM,
0 жалоб.

## Неделя 2. Ручной аутрич

Каждый день — 10 персонализированных сообщений админам открытых сообществ.
Не массовая рассылка: только публичный контакт из карточки, только по делу.

Что предлагать:

1. **Взаимный пиар.** Мы даём их сообществу полезный разбор или пост,
   они — упоминание у себя. Без денег.
2. **Бартер.** Админ получает ГДЗ+ на 30 дней, сообщество — бесплатный
   разбор по заявкам. Мы не просим доступ к аккаунту.
3. **Платное размещение.** Фиксированная цена за пост, маркировка рекламы,
   отчёт по UTM. Начинать с 1–2 площадок, не покупать «пакеты на всё».
4. **Промокод для подписчиков.** Создаётся вручную в админке; код уникален
   для сообщества, срок 7–14 дней. Без кода не обещаем скидку.

Шаблон первого сообщения:

> Здравствуйте. Я делаю ГДЗ НЭЛ — бесплатный поиск решений по номеру
> учебника. Не предлагаю спам и рассылку. Хочу предложить вашему сообществу
> один полезный разбор по заявкам или взаимный пиар. Если формат интересен,
> пришлю пример поста и ссылку. Если нет — больше не пишу.

Если ответа нет — один вежливый follow-up через 5–7 дней. После отказа
больше не контактируем. Ведём таблицу: сообщество, админ, дата, статус,
условия, результат.

Метрики недели: 50 контактов, 8 ответов, 2–3 договорённости, 100 переходов.

## Неделя 3. Комментарии и школьные чаты

Где работаем:

- комментарии под нашими постами;
- комментарии в сообществах, где админ разрешил отвечать;
- школьные чаты, куда нас пригласили, по правилам чата.

Как отвечать:

1. Сначала разбираем вопрос по шагам, без ссылки.
2. Если человек просит ссылку — даём один URL на конкретное задание, не на
   главную.
3. Не отвечаем одинаковой простынёй в десяти чатах. Один вопрос — один
   ответ.
4. Раскрываем авторство: «я делаю этот сайт, поэтому даю ссылку».
5. Не спорим с учителями и не публикуем чужие домашние задания.

Что не делаем:

- не вставляем ссылку в каждый комментарий;
- не пишем в чаты без приглашения;
- не используем несколько аккаунтов;
- не скупаем админов и не просим «просто удалить конкурентов».

Метрики недели: 30 полезных ответов, 5 переходов из комментариев,
0 блокировок.

## Неделя 4. Рефералка и конкурс

Реферальная механика уже есть в профиле:

- пользователь открывает `profile.html`;
- копирует ссылку `auth.html?ref=КОД`;
- друг регистрируется, подтверждает почту;
- пригласивший получает +3 дня ГДЗ+ за каждого уникального друга.

Что делаем:

1. Пост «+3 дня за друга» в Telegram и VK.
2. Мини-конкурс: до конца месяца собираем заявки на разборы; авторы
   трёх самых полезных вопросов получают ГДЗ+ на 30 дней вручную.
3. Проверяем цепочки: один человек — один аккаунт, без временных почт.
4. Показываем прозрачный итог: сколько ссылок, сколько подтверждённых
   регистраций, сколько дней начислено.

Метрики недели: 20 реферальных переходов, 5 подтверждённых регистраций,
3 разбора, 0 фрод-цепочек.

## SEO и индексация

- 50 старых SEO-страниц и 20 новых должны быть в `sitemap.xml`.
- IndexNow отправляет все URL из sitemap; перед пингом проверяется key-файл.
- Google Search Console: отправить sitemap вручную, если нет OAuth-токена.
- Яндекс.Вебмастер: добавить sitemap и следить за ошибками.
- Внутренние ссылки: из SEO-страниц в приложение и на соседние номера.
- Title и description не обещают «списать»; только условие, решение, ответ.
- Один URL — одна задача. Не плодим дубли под каждую формулировку.

## Метрики и отчётность

Смотреть раз в неделю:

- переходы по UTM: source, content, landing page;
- регистрации и подтверждения почты;
- использование поиска, фото, офлайна;
- возвраты через 7 дней;
- реферальные регистрации и начисления;
- позиции в Яндексе и Google по 10 контрольным запросам;
- жалобы и удаления.

Не считать успехом:

- показы без переходов;
- переходы без регистрации;
- регистрации без подтверждения;
- «подписчики», купленные в накрутке.

## Бюджет

Вариант 0 рублей:

- свои Telegram и VK;
- взаимный пиар;
- SEO и IndexNow;
- комментарии по правилам;
- рефералка.

Вариант 5–10 тысяч рублей:

- 2–3 платных поста в локальных сообществах;
- 1–2 промокода для подписчиков;
- тест разных креативов, не больше 2 площадок.

Вариант 15+ тысяч:

- серия постов у школьных блогеров;
- конкурс с призами;
- аналитика по UTM и ручная проверка каждого размещения.

## Что нужно от владельца

1. VK_ACCESS_TOKEN с правами `groups` и `wall`.
2. VK_GROUP_ID своей группы.
3. GSC_ACCESS_TOKEN или ручная отправка sitemap в Search Console.
4. Решение по промокодам: какие коды и на какой срок создавать.
5. Подтверждение, что можно публиковать посты в @gdz_nel.

Без VK-токена поиск сообществ и VK-автопостинг не запускаются. Это
единственный блокер, который нельзя обойти легально.
