## 18.10.2026 — отзывы на проде: пост-модерация + фикс кэша service worker

Симптом: отзыв отправлялся (POST 201), но не появлялся на странице — ни сразу, ни после перезагрузки.

Разбор (воспроизведено на проде под тестовым юзером):
- консоль чистая, 401/403/CORS нет — запись в базу проходит;
- причина 1: вебхук ИИ-модерации moderate-review не развёрнут (404/502 в `net._http_response`),
  `is_approved` навсегда оставался false;
- причина 2: service worker кэшировал GET-ответы Supabase REST по стратегии cache-first —
  первый (пустой) список отзывов залипал в кэше навсегда.

Решение:
- миграция `20261018150000_reviews_postmoderation.sql`: `is_approved` default true (отзыв
  публикуется сразу, ИИ-модерация работает постфактум и может скрыть нарушение), политика
  INSERT упрощена до `user_id = auth.uid() and not is_banned()`, висевшие pending-отзывы
  опубликованы;
- service worker v5: чужие домены (Supabase API) не кэшируются вообще, кэш только для
  картинок с внешних CDN;
- фронт: тост «Отзыв успешно добавлен», принудительный re-fetch через 1.5 c, бейдж
  «опубликован»/«на проверке»/«отклонён» по is_approved + ai_status;
- бонус: виджет lava.top невозможно встроить (сервер отдаёт X-Frame-Options: DENY и
  frame-ancestors 'self') — на premium.html кнопка ведёт на страницу оплаты Lava напрямую;
- `[hidden] { display: none !important }` в общем CSS — плашка ГДЗ+ на фото больше не
  показывается премиум-юзерам вопреки атрибуту hidden.
