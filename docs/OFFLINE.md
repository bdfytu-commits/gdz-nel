# Офлайн-режим и APK

## Что скачивается

В приложении на экране предмета у каждого учебника есть кнопка
«Скачать для офлайна». Она:

1. загружает JSON учебника;
2. раскладывает задания в IndexedDB (`tasks`);
3. скачивает привязанные картинки и сохраняет их Blob (`images`);
4. пишет метаданные книги в `books` (число заданий, размер, дата).

Кнопка показывает прогресс по заданиям и картинкам. После скачивания
появляется размер и число заданий; повторное нажатие обновляет копию.
Прогресс и состояние хранятся в IndexedDB, а не в HTTP-кэше, поэтому
переживают очистку кэша и перезапуск приложения.

## Интерфейс

- `app/assets/offline-db.js` — IndexedDB и публичный API `window.GdzOffline`.
- `app/assets/script.js` — кнопки на сетке учебников, прогресс-бар,
  резервная загрузка книги из IndexedDB, если сеть недоступна.
- `profile.html` + `assets/offline-profile.js` — блок «Офлайн-учебники»:
  список, размер, удаление. Работает независимо от Supabase.
- `app/offline.html` — аварийная страница внутри scope service worker:
  показывает скачанные книги и объясняет, что делать без сети. Корневой
  `offline.html` — та же страница для прямого открытия.

## Service Worker v12

- навигация: сеть → кэш оболочки → `offline.html`;
- если сети нет и в IndexedDB нет ни одной скачанной книги, вместо
  пустой оболочки сразу отдаётся `app/offline.html`;
- `app/data/*.json`: сеть → IndexedDB (скачанный учебник) → кэш;
- картинки: HTTP-кэш → IndexedDB (Blob) → сеть;
- статика и шрифты: cache first;
- при обновлении старые кэши удаляются, новая версия ждёт команды
  «Обновить» на странице.

## APK

- Пакет: `ru.nel.gdz`, версия **3.1.0 (versionCode 9)**, minSdk 24,
  targetSdk 36.
- Стартовый адрес TWA: `/app/` — приложение сразу открывает ГДЗ, а не
  лендинг.
- Подпись: `android-signing/keystore.jks`, SHA-256
  `B8:A5:1E:…:5D:3A:1F` (второй отпечаток в `assetlinks.json` — старые
  сборки).
- Сборка: `bash scripts/build_apk.sh build` либо Gradle + `apksigner`
  (см. историю в `docs/PROGRESS.md`).
- Файл для скачивания: `download/app.apk`.

## Проверка

```bash
python3 -m http.server 8000
GDZ_BASE=http://127.0.0.1:8000 scripts/venv-shots/bin/python scripts/tests/test_offline.py
```

Тест скачивает учебник Виленкина (926 заданий), отключает сеть, reload-ит
страницу, открывает задание и проверяет, что service worker отдаёт JSON из
IndexedDB. Отдельно проверены картинки: учебник `geo/matveev-6.json`
(7 заданий, 12 сканов) занимает около 3 МБ, после отключения сети картинка
отдаётся из IndexedDB.

## Ограничения

- Картинки с чужих сайтов сначала сохраняются как Blob, если источник
  разрешает CORS (`imgs.euroki.org`). Если CORS нет (`gdz.ru`,
  `gdz-raketa.ru`), service worker кладёт opaque-копию в Cache API; это
  позволяет показать картинку офлайн, но её нельзя прочитать как Blob.
  Текст задания сохраняется в любом случае.
- Размер хранилища ограничен браузером (обычно десятки–сотни МБ).
  Скачивайте нужные предметы, а не весь каталог.
- Для скачивания всех картинок нужен интернет; после загрузки задания и
  картинки доступны без сети.
