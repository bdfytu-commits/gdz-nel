# ГДЗ НЭЛ

Статический сайт с готовыми домашними заданиями для 6 класса МАОУ «Новосибирский экономический лицей».
Никакого бэкенда: HTML + CSS + vanilla JS, данные — JSON-файлы, читаются через fetch.

## Структура

```
gdz-nel/
  index.html                  лендинг
  assets/                     стили, скрипт и эмблема лендинга
  download/app.apk            заглушка APK (собирается отдельно через Bubblewrap)
  app/
    index.html                приложение с ГДЗ
    assets/                   стили и скрипт приложения
    data/
      catalog.json            каталог: предметы, учебники, файлы заданий
      math/                   виленкин-6-1.json, виленкин-6-2.json
      russian/                ладыженская-6-1.json, ладыженская-6-2.json
      english/                ваулина-6.json
      biology/                пасечник-6.json
      history/                мединский-6.json
      social/                 боголюбов-6.json
```

## Запуск локально (fish)

```fish
cd gdz-nel
uv run python -m http.server 8000
```

Открыть http://localhost:8000

Важно: открывать index.html двойным кликом нельзя — браузер запрещает fetch с file://.
Нужен любой локальный сервер или хостинг.

## Деплой

GitHub Pages: залить репозиторий, Settings → Pages → Deploy from a branch → main / (root).
Cloudflare Pages: подключить репозиторий, build command оставить пустым, output directory — корень.
Все пути относительные, работает и там, и там.

## Формат данных

`app/data/catalog.json` — каталог предметов:

```json
{
  "id": "math",
  "title": "Математика",
  "active": true,
  "textbooks": [
    { "id": "vilenkin-6-1", "title": "Виленкин. Часть 1",
      "author": "Виленкин Н.Я., Жохов В.И., Чесноков А.С.",
      "year": "2021–2026", "file": "math/vilenkin-6-1.json" }
  ]
}
```

`active: false` — карточка предмета становится серой с надписью «скоро».

Файл учебника (`app/data/<предмет>/<учебник>.json`):

```json
{
  "subject": "math",
  "textbook": "vilenkin-6-1",
  "author": "Виленкин Н.Я., Жохов В.И., Чесноков А.С.",
  "year": "2021–2026",
  "part": 1,
  "tasks": [
    {
      "number": 1,
      "condition": "текст условия",
      "solution": "шаг 1\nшаг 2\nшаг 3",
      "answer": "краткий ответ"
    }
  ]
}
```

## Как наполнить заданиями

1. Открыть нужный файл в `app/data/<предмет>/`.
2. Добавить объект в массив `tasks`. В `solution` переносы строк (`\n`) превратятся в отдельные абзацы.
3. Номера должны идти подряд от 1. Пропущенный номер показывается серой некликабельной кнопкой — это нормально, так и задумано для отсутствующих заданий.
4. Новый учебник — добавить запись в `catalog.json` и положить файл рядом.

## Маршруты (хэш-роутинг, ссылку можно скинуть)

```
#/                        выбор предмета
#/math                    выбор учебника
#/math/vilenkin-6-1       сетка заданий
#/math/vilenkin-6-1/12    задание 12
```

## Решения, принятые без согласования

- `assets/img/logo.svg` — нарисованная заглушка по описанию эмблемы (бирюзовая обводка, синяя птица, три столбика диаграммы). Чтобы поставить настоящую эмблему — заменить файл, имя оставить тем же.
- `download/app.apk` — текстовая заглушка, ссылка на неё уже в лендинге. Настоящий APK — через PWA + Bubblewrap (шаг ниже).
- Предмет с одним учебником открывается сразу на сетке заданий, минуя экран выбора. С двумя (математика, русский) — показывает выбор частей.
- Неактивные предметы реализованы через `active: false` в каталоге. Сейчас все шесть активны, потому что для всех есть тестовые данные.
- Сетка заданий строится от 1 до последнего номера из JSON; дыры — серые кнопки.
- Поиск фильтрует по началу номера (ввод «1» покажет 1, 10, 11, 12).
