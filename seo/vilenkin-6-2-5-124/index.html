Виленкин. Математика, 6 класс, номер 5.124

Условие

Решите уравнение: а) −5 (−y + 9) = y + 10; б) m − 17 = (m + 4)(−9); в) 17 − 4(m + 11) = 43; г) −7(4x + 2) − 3 = −17; д) −4,8y + 7,2 = 3(2,4y + 4,8); е) −5(0,6y − 1,8) = −2y + 8,5.

Решение

а) −5 (−y + 9) = y + 10; 5у – 45 = у + 10; 5у – у = 10 + 45; 4у = 55; у = 55 : 4; у = 133/4. Проверка: −5 ∙ (−133/4 + 9) = −5 ∙ (−43/4) = 5 ∙ 19/4 = 95/4 = 233/4; 133/4 + 10 = 233/4; 233/4 = 233/4 – верно. Ответ: 133/4. б) m − 17 = (m + 4)(−9); m − 17 = −9m – 36; m + 9m = −36 + 17; 10m = −19; m = −19 : 10; m = −1,9. Проверка: −1,9 − 17 = − 18,9; (−1,9 + 4) ∙ (−9) = 2,1 ∙ (−9) = −18,9; −18,9 = −18,9 – верно. Ответ: m = −1,9. в) 17 − 4(m + 11) = 43; 17 – 4m – 44 = 43; −4m = 43 + 44 – 17; −4m = 70; m = 70 : (−4); m = −17,5. Проверка: 17 – 4 ∙ ((−17,5) + 11) = 17 – 4 ∙ (−6,5) = 17 + 26 = 43; 43 = 43 – верно. Ответ: m = -17,5. г) −7(4x + 2) − 3 = −17; −28х – 14 – 3 = −17; −28х = −17 + 14 + 3; −28х = 0; х = 0. Проверка: −7 ∙ (4 ∙ 0 + 2) − 3 = −7 ∙ 2 – 3 = −14 – 3 = −17; −17 = −17 – верно. Ответ: х = 0. д) −4,8y + 7,2 = 3(2,4y + 4,8); −4,8у + 7,2 = 7,2у + 14,4; −4,8у – 7,2у = 14,4 – 7,2; −12у = 7,2; у = 7,2 : (−12); у = −72 : 12; у = −0,6. Проверка: −4,8 ∙ (−0,6) + 7,2 = 2,88 + 7,2 = 10,08; 3 ∙ (2,4 ∙ (−0,6) + 4,8) = 3 ∙ (−1,44 + 4,8) = 3 ∙ 3,36 = 10,08; 10,08 = 10,08 – верно. Ответ: у = −0,6. е) −5(0,6y − 1,8) = −2y + 8,5; −3у + 9 = −2у + 8,5; −3у + 2у = 8,5 – 9; −у = −0,5; у = 0,5. Проверка: −5 ∙ (0,6 ∙ 0,5 − 1,8) = −5 ∙ (0,3 – 1,8) = −5 ∙ (−1,5) = 7,5; −2 ∙ 0,5 + 8,5 = −1 + 8,5 = 7,5; 7,5 = 7,5 – верно. Ответ: у = 0,5.

Ответ

Ответ: у = 0,5.
